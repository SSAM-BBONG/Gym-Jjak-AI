# 안내 원칙

*[안내 원칙]*

1. 먼저 사용자의 역할이 일반 사용자, 트레이너, 조직 중 무엇인지 확인합니다.
2. 사용자가 현재 어느 화면에 있는지 알 수 없다면 홈 화면을 출발점으로 안내합니다.
3. 반드시 화면에 표시되는 실제 메뉴명과 버튼명을 사용합니다.
4. 다음 순서로 짧고 명확하게 안내합니다: 현재 화면 → 클릭할 메뉴 → 클릭할 버튼 → 입력 또는 선택할 내용 → 완료 후 상태.
5. 로그인이 필요한 기능이면 안내 시작 전에 로그인이 필요하다고 설명합니다.
6. 모바일에서는 헤더 메뉴가 보이지 않을 수 있으므로 '상단 햄버거 메뉴'를 먼저 열도록 안내합니다.
7. 사용자가 접근할 수 없는 역할 전용 페이지는 안내하지 않습니다.
8. 화면 주소는 사용자가 직접 요청했을 때만 안내합니다.
9. 상세 페이지 주소는 항목마다 달라지므로 임의로 추측해서 알려주지 않습니다.
10. 현재 화면에서 실제로 동작하지 않는 버튼이나 아직 제공되지 않는 기능은 이용할 수 있다고 안내하지 않습니다.

# 공통

## 로그인

*[공통] 로그인*

로그인은 헤더 오른쪽의 `로그인` 버튼을 누른 뒤 아이디와 비밀번호를 입력하고 `로그인`을 누르면 됩니다.

## 회원가입

*[공통] 회원가입*

회원가입은 `로그인` 화면 하단의 `회원가입`을 눌러 회원 정보를 입력하면 됩니다. 가입이 완료되면 로그인 화면으로 이동합니다.

## 비밀번호 찾기

*[공통] 비밀번호 찾기*

비밀번호를 잊었다면 `로그인` 화면의 `비밀번호 찾기`를 눌러 가입한 정보를 입력하면 비밀번호를 다시 설정할 수 있습니다.

## 마이페이지 이동

*[공통] 마이페이지 이동*

헤더 오른쪽의 프로필 이미지를 누르면 `마이페이지`로 이동할 수 있습니다. (로그인 필요)

## 알림 확인

*[공통] 알림 확인*

헤더 오른쪽의 종 모양 `알림` 버튼을 누르면 알림 목록이 나타나며, 원하는 알림을 선택해 확인할 수 있습니다. (로그인 필요)

## 채팅 확인

*[공통] 채팅 확인*

헤더 오른쪽의 `채팅` 버튼을 누르면 채팅방 목록이 나타나며, 원하는 채팅방을 선택해 대화를 확인할 수 있습니다. (로그인 필요)

## AI 챗봇 이용

*[공통] AI 챗봇 이용*

화면 오른쪽 아래의 챗봇 버튼을 누르면 챗봇 화면으로 이동합니다.

## AI 챗봇 대화 관리

*[공통] AI 챗봇 대화 관리*

새 대화를 시작하려면 챗봇 화면 왼쪽의 `새 채팅`을 누르면 됩니다. 이전 대화를 다시 보고 싶다면 챗봇 화면의 대화 목록에서 원하는 대화 제목을 선택하면 됩니다.

## 로그아웃

*[공통] 로그아웃*

헤더 오른쪽의 프로필 이미지를 누른 뒤 `로그아웃`을 선택하면 됩니다.

## 커뮤니티 이동

*[공통] 커뮤니티 이동*

헤더의 `커뮤니티`를 누르면 이동합니다.

## 모바일 메뉴

*[공통] 모바일 메뉴*

모바일 화면에서 메뉴가 보이지 않으면 상단의 햄버거 메뉴를 눌러 원하는 메뉴를 선택하면 됩니다.

# 일반 사용자 · PT

## PT 찾기

*[일반 사용자 · PT] PT 찾기*

헤더의 `PT ZONE`에서 `PT 찾기`를 누르면 지역별 목록이나 전체 PT 목록을 확인할 수 있습니다. 원하는 PT 카드를 선택하면 상세 정보를 볼 수 있습니다. PT 카드에서는 트레이너, 가격, 횟수, 평점과 리뷰를 확인할 수 있고, 목록에서 `헬스장 조회`를 누르면 해당 헬스장의 PT 목록만 따로 볼 수 있습니다.

## AI 맞춤 추천

*[일반 사용자 · PT] AI 맞춤 추천*

홈 화면의 맞춤 PT 추천 영역에서 추천 시작 버튼을 누르고 질문에 맞춰 조건을 선택하면 추천 PT를 확인할 수 있습니다. (로그인 필요)

## 상세 정보와 리뷰

*[일반 사용자 · PT] 상세 정보와 리뷰*

`PT ZONE` → `PT 찾기` → 원하는 PT 선택 순서로 이동하면 상세 화면에서 트레이너 정보, 커리큘럼, 가격을 확인할 수 있습니다. 전체 리뷰는 상세 화면의 `전체 리뷰 보기`에서 최신순 또는 평점 높은 순으로 볼 수 있습니다.

## PT 결제

*[일반 사용자 · PT] PT 결제*

`PT ZONE` → `PT 찾기` → 원하는 PT 선택 → `결제하기` → 결제 정보 확인 → 결제 진행 순서로 이용합니다. 이미 결제한 PT라면 `결제하기` 대신 `예약하기`가 표시됩니다. 결제 처리 상태가 불확실할 때는 `결제 상태 다시 확인` 버튼이 나타날 수 있습니다. (로그인 필요)

## 트레이너 문의

*[일반 사용자 · PT] 트레이너 문의*

PT 상세 화면에서 `채팅하기`를 누르면 채팅방이 만들어지고, 그 안에서 메시지를 보낼 수 있습니다. (로그인 필요)

## 세션 예약

*[일반 사용자 · PT] 세션 예약*

결제를 마친 PT는 상세 화면의 `예약하기`에서 예약 가능한 날짜와 시간을 선택하면 예약이 완료됩니다. (로그인 필요)

## 이용 내역 확인

*[일반 사용자 · PT] 이용 내역 확인*

`PT ZONE` → `PT 기록`에서 진행 중, 완료, 취소됨 등 상태별로 목록을 확인하고, 원하는 PT의 상세보기를 누르면 자세한 내용을 볼 수 있습니다. (로그인 필요)

## 예약 세션 목록 확인

*[일반 사용자 · PT] 예약 세션 목록 확인*

`PT ZONE` → `PT 기록` → 해당 PT의 세션 예약 목록에서 확인하거나, `마이페이지` → `내 활동` → `전체 PT 예약 확인`에서도 볼 수 있습니다. 예약 내역에서는 예정된 세션을 `세션 취소`할 수 있습니다. (로그인 필요)

## 예약 취소

*[일반 사용자 · PT] 예약 취소*

PT 전체를 취소하려면 `PT ZONE` → `PT 기록` → 해당 PT 카드의 `PT 취소하기` → 확인 순서로 진행합니다. 세션 하나만 취소하려면 `마이페이지` → `전체 PT 예약 확인` → 취소할 세션의 `세션 취소` → 확인 순서로 진행합니다. PT 예약 취소는 수업일 하루 전까지만 가능하며, 수업 당일 취소도 가능하지만 이 경우 회차가 차감됩니다. 당일 취소가 필요하면 담당 트레이너님에게 미리 말씀해 주세요. (로그인 필요)

## 트레이너 피드백 확인

*[일반 사용자 · PT] 트레이너 피드백 확인*

`PT ZONE` → `PT 기록` → 해당 PT의 상세보기에서 트레이너 피드백을 확인할 수 있습니다. (로그인 필요)

# 일반 사용자 · 트레이너 신청

## 트레이너 되기

*[일반 사용자 · 트레이너 신청] 트레이너 되기*

`PT ZONE` → `트레이너 등록` → `신청하기`에서 프로필, 자격 및 경력, 소속 헬스장 등 신청 정보를 입력하고 `신청하기`를 누르면 관리자 승인을 기다리게 됩니다. 승인에는 화면 안내 기준 영업일 3~5일이 소요될 수 있고, 신청 상태는 대기중, 승인됨, 거절됨, 취소됨으로 확인할 수 있습니다. `마이페이지` → 회원 프로필 수정 영역의 `트레이너 신청`에서도 같은 화면으로 이동할 수 있습니다. (로그인 필요)

## 신청 상태·수정·취소

*[일반 사용자 · 트레이너 신청] 신청 상태·수정·취소*

`PT ZONE` → `트레이너 등록`에서 신청 목록 중 원하는 신청을 선택하면 현재 상태를 확인할 수 있습니다. 대기 중이거나 수정 가능한 신청은 `수정하기`를 눌러 내용을 바꾸고 `수정하기`로 저장할 수 있습니다. 신청을 취소하려면 해당 신청을 선택한 뒤 `신청취소` → 확인 순서로 진행합니다. (로그인 필요)

# 일반 사용자 · 식단

## 식단 기록

*[일반 사용자 · 식단] 식단 기록*

헤더의 `식단`에서 원하는 날짜를 선택하고 오른쪽 상단의 추가 버튼을 눌러 식사 정보와 영양 정보(칼로리, 탄수화물, 단백질, 지방 등)를 입력한 뒤 저장하면 됩니다. (로그인 필요)

## 식단 수정·삭제

*[일반 사용자 · 식단] 식단 수정·삭제*

`식단`에서 수정할 식단 카드를 선택한 뒤 `수정하기` 또는 `삭제하기`를 누르면 됩니다. (로그인 필요)

## AI 식단 분석

*[일반 사용자 · 식단] AI 식단 분석*

`식단` → 추가 버튼 → AI 식단 입력 화면에서 음식 정보를 입력하거나 분석을 진행하면 결과를 확인할 수 있습니다. 구독 상태에 따라 일반 식단 등록 화면과 AI 입력 화면이 다르게 표시되며, 구독이 필요한 기능에서는 요금제 화면으로 안내될 수 있습니다. (로그인 필요)

## 영양 목표 설정·수정

*[일반 사용자 · 식단] 영양 목표 설정·수정*

`식단`의 오늘의 영양 목표 카드에서 탄수화물, 단백질, 지방 목표를 입력하고 저장하면 됩니다. 기존 목표를 수정하거나 삭제하려면 같은 카드를 선택한 뒤 `수정하기` 또는 `삭제하기`를 누르면 됩니다. (로그인 필요)

# 일반 사용자 · 캘린더

## 운동일지 작성·수정·삭제

*[일반 사용자 · 캘린더] 운동일지 작성·수정·삭제*

헤더의 `캘린더`에서 날짜를 선택하고 일정 추가 버튼을 눌러 운동 종류와 세트별 무게·횟수를 입력한 뒤 저장하면 됩니다. 기존 기록을 수정하거나 삭제하려면 해당 날짜의 운동일지를 선택한 뒤 `수정하기` 또는 `삭제하기`를 누르면 됩니다. (로그인 필요)

## PT 일정 확인

*[일반 사용자 · 캘린더] PT 일정 확인*

헤더의 `캘린더`에서 날짜를 선택하면 표시된 PT 일정을 확인할 수 있고, 해당 항목을 선택하면 PT 상세 화면으로 이동합니다. (로그인 필요)

# 일반 사용자 · 커뮤니티

## 게시글 보기·검색

*[일반 사용자 · 커뮤니티] 게시글 보기·검색*

헤더의 `커뮤니티`에서 전체, 자유, 공지 중 카테고리를 선택해 게시글을 볼 수 있고, 정렬과 검색 기능도 사용할 수 있습니다. 검색은 검색창에 검색어를 입력하고 검색을 누르면 됩니다.

## 게시글 작성·수정·삭제

*[일반 사용자 · 커뮤니티] 게시글 작성·수정·삭제*

`커뮤니티` → `글쓰기`에서 제목, 카테고리, 내용을 입력하고 저장하면 게시글이 등록됩니다. 본인이 작성한 글은 `내 게시글`에서 선택해 수정하거나 삭제할 수 있습니다. (로그인 필요)

## 댓글·좋아요

*[일반 사용자 · 커뮤니티] 댓글·좋아요*

게시글을 선택한 뒤 댓글을 입력하고 등록하거나, 게시글 상세 화면의 좋아요 버튼을 누르면 됩니다. (로그인 필요)

## 내가 쓴 글 모아보기

*[일반 사용자 · 커뮤니티] 내가 쓴 글 모아보기*

`마이페이지` → `내 활동` → `내가 쓴 글`에서 확인할 수 있습니다. (로그인 필요)

# 일반 사용자 · 마이페이지

## 프로필 수정

*[일반 사용자 · 마이페이지] 프로필 수정*

`마이페이지` → 회원 프로필에서 현재 비밀번호를 확인한 뒤 이름이나 프로필 정보를 수정하고 저장하면 됩니다. (로그인 필요)

## 온보딩 정보 확인·수정

*[일반 사용자 · 마이페이지] 온보딩 정보 확인·수정*

`마이페이지` → 온보딩 정보 → `수정하기`에서 운동 목적과 신체 정보 등을 수정하고 저장하면 됩니다. (로그인 필요)

## 인바디 등록·수정·삭제

*[일반 사용자 · 마이페이지] 인바디 등록·수정·삭제*

`마이페이지` → 인바디 입력에서 측정일, 키, 몸무게, 체지방률, 골격근량을 입력하고 저장하면 됩니다. 기존 기록을 수정하거나 삭제하려면 해당 기록을 선택하면 됩니다. (로그인 필요)

## 결제·구독 확인

*[일반 사용자 · 마이페이지] 결제·구독 확인*

결제 내역은 `마이페이지` → `내 활동` → `결제 내역`에서, 구독 상태는 `내 활동` → `나의 구독`에서 확인할 수 있습니다. 구독 상품 종류는 `나의 구독` → `구독 상품 보기`에서 볼 수 있고, 이용 중인 구독이 없다면 요금제 화면에서 월간 또는 연간 상품을 선택할 수 있습니다. (로그인 필요)

## 비밀번호 변경

*[일반 사용자 · 마이페이지] 비밀번호 변경*

`마이페이지` → 계정 설정 → `비밀번호 변경`에서 현재 비밀번호를 확인한 뒤 새 비밀번호를 입력하고 변경하면 됩니다. (로그인 필요)

## 회원 탈퇴

*[일반 사용자 · 마이페이지] 회원 탈퇴*

`마이페이지` → 계정 설정 → `회원 탈퇴` → 확인 순서로 진행합니다. 탈퇴는 이후 복구하기 어려운 절차이므로, 안내 시 이 점을 먼저 알려야 합니다. (로그인 필요)

# 일반 사용자 · 조직 계정 신청

## 헬스장 계정 신청

*[일반 사용자 · 조직 계정 신청] 헬스장 계정 신청*

`마이페이지`의 조직 계정 신청 영역에서 `신청하기`를 누르고 조직 정보, 사업자 정보, 사업자등록증, 주소 등을 입력한 뒤 신청하면 관리자 승인을 기다리게 됩니다. 승인되면 신청 시 입력한 이메일로 조직 계정 정보가 발송됩니다. (로그인 필요)

## 신청 확인·취소

*[일반 사용자 · 조직 계정 신청] 신청 확인·취소*

`마이페이지` → 조직 계정 신청 내역에서 신청을 확인할 수 있고, 취소하려면 해당 신청을 선택한 뒤 신청 취소 → 확인 순서로 진행합니다. (로그인 필요)

# 트레이너

## 전체 안내

*[트레이너] 전체 안내*

트레이너 계정의 데스크톱 헤더에는 기본적으로 `PT ZONE`과 `커뮤니티`가 표시됩니다. 식단과 캘린더는 트레이너 개인용 메뉴가 아니라, 수강생 관리 화면 안에서 해당 수강생의 정보로 확인합니다.

# 트레이너 · PT 관리

## PT 등록

*[트레이너 · PT 관리] PT 등록*

`PT ZONE` → `PT 등록`에서 프로그램 정보, 가격, 총 횟수, 커리큘럼을 입력하고 등록하기를 누르면 됩니다.

## 등록한 PT 확인·수정·삭제

*[트레이너 · PT 관리] 등록한 PT 확인·수정·삭제*

`PT ZONE` → `PT 관리`에서 관리할 프로그램을 선택해 확인할 수 있습니다. 수정하려면 해당 PT의 더보기 메뉴 → `수정하기`에서 내용을 바꾸고 저장하면 됩니다. 삭제하려면 더보기 메뉴 → `삭제하기` → 확인 순서로 진행하며, 삭제 전에는 해당 PT와 수강생에게 미치는 영향을 함께 안내해야 합니다.

# 트레이너 · 수강생 관리

## 신청자·수강생 확인 및 상태 변경

*[트레이너 · 수강생 관리] 신청자·수강생 확인 및 상태 변경*

`PT ZONE` → `PT 관리` → 관리할 프로그램을 선택하면 신청자와 수강생 목록을 확인할 수 있습니다. 수강생 카드에서 상태를 선택하면 승인, 진행, 완료, 취소 등으로 진행 상태를 변경할 수 있습니다.

## 수강생과 채팅

*[트레이너 · 수강생 관리] 수강생과 채팅*

`PT 관리` → 프로그램 선택 → 해당 수강생의 `채팅하기`에서 채팅방을 열고 메시지를 보낼 수 있습니다.

## 피드백 작성·수정·삭제

*[트레이너 · 수강생 관리] 피드백 작성·수정·삭제*

`PT 관리` → 프로그램 선택 → 해당 수강생의 `피드백 작성` → 피드백 관리 → 등록할 주차 선택 → 등록하기 순서로 진행합니다. 피드백에는 동영상 또는 글로 된 피드백을 남길 수 있으며, 예약된 수업 시작 시간 이후부터 등록할 수 있습니다. 기존 피드백을 수정하거나 삭제하려면 피드백 관리에서 해당 피드백을 선택하면 됩니다.

## 수강생 운동일지·식단 확인

*[트레이너 · 수강생 관리] 수강생 운동일지·식단 확인*

`PT 관리` → 프로그램 선택 → 해당 수강생 선택 후, `운동일지` 탭 또는 `식단관리` 탭에서 확인할 수 있습니다. 수강생 상세 화면은 `피드백 관리`, `운동일지`, `식단관리` 세 탭으로 구성되어 있습니다.

# 트레이너 · 정보

## 트레이너 프로필 수정

*[트레이너 · 정보] 트레이너 프로필 수정*

`마이페이지` → `트레이너 프로필 수정`에서 정보를 바꾸고 저장하면 됩니다.

## 시장 분석 보고서

*[트레이너 · 정보] 시장 분석 보고서*

`PT ZONE` → `트레이너 시장 분석`에서 보고서 목록 중 원하는 보고서를 선택하면 됩니다. 보고서가 없을 때는 `PT ZONE`으로 돌아갈 수 있습니다.

# 트레이너 · 공통

## 커뮤니티, 결제·구독

*[트레이너 · 공통] 커뮤니티, 결제·구독*

커뮤니티 이용, 글 작성, 댓글, 좋아요, 본인 게시글 수정·삭제 방법은 일반 사용자와 동일합니다. 결제나 구독 정보는 `마이페이지` → `결제 내역` 또는 `나의 구독`에서 확인할 수 있습니다.

# 조직 · 트레이너 관리

## 소속 트레이너 확인

*[조직 · 트레이너 관리] 소속 트레이너 확인*

왼쪽 사이드바 → `헬스장 관리` → `트레이너 관리` → 상단의 `트레이너 관리` 탭에서 소속 트레이너의 이메일, 이름, 닉네임, 등록일을 확인할 수 있습니다.

## 트레이너 신청 승인

*[조직 · 트레이너 관리] 트레이너 신청 승인*

왼쪽 사이드바 → `헬스장 관리` → `트레이너 관리` → 상단의 `트레이너 승인` 탭에서 신청자를 검색하거나 목록을 확인한 뒤, `상세` 버튼으로 신청 내용을 확인하고 승인 또는 거절할 수 있습니다.

## 트레이너 직접 추가·삭제

*[조직 · 트레이너 관리] 트레이너 직접 추가·삭제*

현재 조직 화면에서는 소속 트레이너 목록 조회와 신청 승인 기능만 이용할 수 있습니다. 트레이너를 직접 추가하거나 삭제하는 기능은 현재 제공되지 않으므로, 이 기능은 이용할 수 있다고 안내하지 않습니다.

# 조직 · 계정 관리

## 헬스장 정보 확인

*[조직 · 계정 관리] 헬스장 정보 확인*

왼쪽 사이드바 → `계정 관리` → `헬스장 정보`에서 확인할 수 있습니다.

## 비밀번호 변경

*[조직 · 계정 관리] 비밀번호 변경*

# 조직 · 공통

## 커뮤니티, 화면 이동, 로그아웃

*[조직 · 공통] 커뮤니티, 화면 이동, 로그아웃*

조직 화면 상단 헤더의 `커뮤니티`를 누르면 커뮤니티로 이동합니다. 상단의 짐짝 로고를 누르면 헬스장 통계 화면으로 돌아갑니다. 로그아웃은 조직 화면 오른쪽의 프로필 → `로그아웃`을 누르면 됩니다.
